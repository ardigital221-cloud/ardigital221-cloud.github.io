# Carlos Prado Clone

This repo includes:
- a static snapshot of `https://carlosprado.dev/`
- a local live mirror server for 1:1 viewing on your machine

## View 1:1 locally (recommended)

```powershell
npm install
npm run start
```

Then open:

`http://localhost:4173`

## Static snapshot

Static files are in the repo root (`index.html`, `/about`, `/contact`, `/_nuxt`, `/img`, `/fonts`).

## Visual check

```powershell
npm run check:visual
```

Outputs are saved to `visual-check/`.
